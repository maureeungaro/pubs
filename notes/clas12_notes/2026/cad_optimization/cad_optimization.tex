\notetitle{Performance and geometry validation of optimized CLAS12 CAD models}
\vspace{18pt}
\noteauthor{Maurizio Ungaro}
\vspace{8pt}
\noteaffiliation{Jefferson Lab, 12,000 Jefferson Avenue, 23606 Newport News, VA, USA}
\vspace{6pt}
\notenumberdate{October 22, 2026}
\begin{noteabstract}
This study documents CAD volumes optimizations for the LTCC, Beamline, FT, HTCC, and Torus components.
As an example, the optimized LTCC model contains 94\% fewer triangles, with
median initialization CPU time reduced by 63\% and startup peak memory by 57\%.
In a few cases various volumes, originally separated, were merged to avoid overlaps and reduce the number of triangles.
The optimization was performed with the help of codex agent GPT-6.1 Sol.

\end{noteabstract}
